# 功能擴充構想（2026-07-22 live 驗證時觀察到，供下一輪升級參考）

## 高價值

1. **AI 配方範本**（儀表板「使用我們的 AI 範本，輕鬆建立活動」：討論板/課堂活動建立器/課程計畫/課堂活動靈感，皆標「新」）
   這跟 API 的 `create-ai-board`（`ai-recipe-boards` 端點）本質相同，但 UI 版本可能有更豐富的預設模板選擇。
   → `pw/create-board.mjs` 加 `--ai-template <name>` 選項，走這些預製模板而非空白版面，適合老師想要「課堂活動建立器」這類現成骨架。

2. **內容匯入來源**（「製作 padlet」畫面頂部「從 Google Slides 匯入」「匯入 PDF」）
   → 可做 `pw/import-content.mjs`，把既有 Google Slides/PDF 直接轉成 Padlet 貼文，適合老師已有簡報教材的情境。

3. **匯出格式擴充**（本輪只確認「匯出 PDF」分頁存在，CSV/Excel/image 未實測）
   → 下一輪需在「分享此看板」面板逐一點開確認每種格式的實際入口與檔名格式，目前 `export-board.mjs` 的 csv/xlsx/image 分支仍是 fallback 猜測。

## 中價值

4. **共同作業者邀請**（分享面板「新增共同作業者」+「邀請」，本輪只做了訪客權限，沒做邀請特定老師協作）
   → `pw/set-sharing.mjs` 加 `--invite <email>` 選項，適合協同教學情境。

5. **隱私選項**（分享面板「需要密碼」「要求訪客登入」「發佈至個人檔案和網路」三個 toggle，本輪完全沒碰）
   → 對需要保護學生資料的老師很重要，可加 `--require-password <pwd>` `--require-login` 參數。

6. **貼文留言/反應**（貼文卡片下方「新增留言」+ 表情符號反應圖示）
   → 可做 `pw/add-comment.mjs`，讓 agent 代老師在學生貼文下留評語（僅在留言者/作者權限下可行）。

7. **Sandbox 類別**（跟看板版面平行的另一大類：白板/腦力激盪網狀圖/簡報/文氏圖/每日一題）
   目前 `create-board.mjs` 的 LAYOUT_LABEL 只涵蓋「建立一個看板」分類，Sandbox 是完全獨立的建立入口，尚未探索其 URL/流程。
   → 下一輪需確認 sandbox 建立流程是否與看板共用同一個「製作」按鈕（可能分頁不同）。

## 低價值／備查

8. **Backpack 權限**（帳號設定齒輪旁「已使用 3 個 Padlet 中的 2 個」配額提示）——免費方案配額限制，建板前應該先檢查配額，避免建到一半才發現額滿。可加一個 quota 檢查腳本。
9. **投影片模式**（頂部導覽「投影片」按鈕，把看板轉成簡報播放）——教學展示用途，跟自動化操作關聯較低。
