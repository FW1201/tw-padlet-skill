# Padlet 模式與執行

- 看板：先讀看板與權限，分欄建立須先取得 section id 再新增貼文；每筆新增後讀回，標記模擬學生內容。
- Sandbox：connector 建立 whiteboard、get_whiteboard_tool_settings 檢查工具；以便條／素材連結設計小組推理任務，讀回內容與可見度；工具可用不代表所有畫布物件可由 connector 建立。
- Arcade：connector 支援指定模板包括配對、分類與排序，要求題目來源及操作規則，生成後進玩家介面逐題試玩。
- Wildcard：不是上述模板的 connector 類型。以既有登入瀏覽器選 Wildcard，準備年級、玩家行動、目標、挑戰、回饋、完成條件及必要素材；可選文件或連結，生成通常需等待，完成後逐輪測試並以一次一項的方式修改。生成超時時先查 My games，不盲目重送。設計與提示詞詳見 [Wildcard 情境遊戲設計與驗收](wildcard-game-design.md)，並依實際操作驗證遊戲循環。
- 公開與訪客角色獨立核對：未列出不代表僅自己可見。

官方來源：https://padlet.help/l/en/article/5wzjc3tuk2 （2026-11-26）；Sandbox 和 Arcade matching 曾 connector 建立讀回，matching 四題實玩正確；Wildcard 已用公開教材連結建立三關方程式平衡遊戲，初版測試錯誤提示、三關與重玩；第二關修正為兩側各除以二後再次三關通關。公開連結是否可跨帳號開啟須另驗。
